# OnePublish v1.0.3

- 发布日期：2026-09-15
- 版本标签：`v1.0.3`
- 对比范围：[v1.0.2...v1.0.3](https://github.com/sperictao/one-publish/compare/v1.0.2...v1.0.3)

## 问题修复

- 彻底修复 Windows 启动阶段批量闪现 Terminal / Console 窗口的问题（#111）。
- Windows 被动仓库扫描改为直接读取 .git/HEAD、refs、packed-refs 与 config，不再启动 git.exe。
- Windows 项目自动解析不再执行 git worktree list，避免深层项目路径导致重复拉起 Git 进程。
- Windows 启动时不再自动执行 PublishRuntime prepare；仅在用户明确点击发布时准备运行时。

## 兼容性与回归保护

- 支持普通仓库、packed refs 与 linked worktree 的本地 Git 元数据解析。
- 显式刷新、fetch 与 publish 行为保持不变。
- 启动链审计确认 Tauri setup、运行时恢复同步、updater 与环境探测不会在普通 Windows 启动中拉起终端进程。

## 验证

- TypeScript、lint、format、unit、E2E、Clippy、Rust tests、contracts 与 cargo audit 全部通过。
- Windows 原生 cargo check --all-targets 通过。
- Windows 被动 Git 元数据读取与项目扫描零 Git 进程专项测试通过。

# 远端发布尝试使用独立的持久状态模型

GitHub workflow 可能在 One Publish 关闭后继续运行，因此远端发布不能复用要求立即结束的本地执行记录。One Publish 在首次不可逆操作前持久化发布尝试，记录版本、commit、tag、当前阶段、workflow run ID 和相关 URL；重启后从已知阶段恢复轮询，不重复提交或推送，失败记录则保留原身份并提供幂等重试。

发布尝试通过计划声明的仓库写、发布身份、产物身份和交付目标命名空间资源租约协调并发，不使用仓库级全局互斥。资源不相交的本机构建、Stable、Nightly 或产物推广可以并行；租约冲突时，新尝试等待或明确失败。

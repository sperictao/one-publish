# Keep real paths in local publish evidence

The attempt journal is local-private (0600) execution evidence, not a presentation surface. Persisted Publish Event payloads mask secrets only — sensitive keys become `<redacted>` and `key=value` secret assignments in free text are redacted — while absolute paths are preserved verbatim, matching the execution-history persistence policy. Path masking happens exclusively at the export boundary (`sanitize_export_value`), so handoff bundles, diagnostics indexes, and history exports still ship sanitized content. Delivery Envelope payloads remain structurally exempt from text redaction and reject credential keys outright. Batches written before this decision keep their masked text; content-addressed batch digests make integrity independent of payload contents, so no backfill is required.

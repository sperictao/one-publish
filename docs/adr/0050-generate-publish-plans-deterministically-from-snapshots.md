# Generate Publish Plans deterministically from snapshots

A Publish Plan is a deterministic function of a configuration revision, runtime and adapter versions, release inputs, explicit source snapshot, and timestamped external-precondition snapshot. Clean builds use an immutable VCS revision; dirty local builds use a digest of provider-declared non-secret workspace inputs without storing the diff. Secret contents never enter snapshots or digests: an opaque secret version may be referenced when the backend supplies one, otherwise the build is marked environment-dependent. Expired conditions are revalidated before execution, but failure blocks instead of silently replanning; time, randomness, and undeclared environment state must enter as explicit release inputs when they affect identity or behavior.

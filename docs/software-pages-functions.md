# OnePublish 页面与功能总览

> 基于当前代码结构总结：`src/App.tsx`、`src/components/layout/*`、`src/components/publish/*`、`src/components/environment/*`、`src/components/release/*`、`src/hooks/*`、`src/features/*`、`src-tauri/src/provider/*`。
>
> 本文按“用户可见页面、面板、弹窗、顶部提示”整理。OnePublish 当前没有传统路由页，主界面由三栏工作台和一组懒加载弹窗组成。每个页面条目中直接包含对应页面布局说明。

## 1. 软件整体定位

OnePublish 是一个跨平台桌面发布工具，用统一图形界面管理本地项目发布流程。当前内置 Provider 包括：

| Provider | 项目定位方式 | 命令导入 | 典型命令 |
|---|---:|---:|---|
| .NET (dotnet) | Project File（`.csproj` / `.fsproj` / `.vbproj` / `.sln`） | 支持 | `dotnet publish ...` |
| Rust (cargo) | Repository Root（`Cargo.toml`） | 支持 | `cargo build ...` |
| Go | Repository Root（`go.mod`） | 支持 | `go build ...` |
| Java (Gradle) | Repository Root（`build.gradle` / `settings.gradle` / `gradlew`） | 支持 | `./gradlew build ...` |

核心工作流：

1. 选择或添加仓库。
2. 自动识别 Provider、项目文件和分支。
3. 选择项目发布配置、自定义配置或最近使用配置。
4. 预览并执行发布命令。
5. 查看实时日志、发布状态、失败原因和执行历史。
6. 从历史记录重跑、导出诊断或复制交接片段。

## 2. 启动加载页

出现时机：应用持久化状态尚未加载完成。

页面布局：

- 全屏 `h-screen` 容器，背景使用应用底色。
- 内容垂直和水平居中。
- 上方是旋转加载图标，下方是加载文案。
- 不显示导航、侧栏或主内容，避免用户看到半初始化状态。

功能：

- 显示全屏加载状态。
- 使用当前语言展示“加载中...”文案。
- 进入主工作台前阻止展示未初始化数据。
- 如果启动时恢复了安全配置，会在进入界面后弹出恢复提示。

## 3. 主工作台页面

主工作台是生产环境的主要页面。

页面布局：

- 根容器为纵向 `flex h-screen`。
- 顶部可显示 Provider Runtime Banner。
- 主体为横向三栏 `flex flex-1 overflow-hidden`：
  - 左栏：仓库列表。
  - 中栏：发布配置列表。
  - 右栏：发布执行 / 历史记录内容区。
- 左栏和中栏宽度来自持久化布局状态，栏间用拖拽手柄分隔。
- 右栏自适应剩余空间，内部内容滚动，主窗口不整体滚动。
- 右栏顶部约 40px 高度保留为拖拽区域，右上角放“主页 / 历史记录”视图切换。
- 左栏或中栏收起后，在右栏顶部或中栏顶部提供展开按钮。

功能：

- 左栏和中栏支持收起、展开。
- 左栏和中栏宽度支持拖拽调整，并持久化。
- 右上角支持在“主页/发布执行”和“历史记录”之间切换。
- 当 Provider 列表或 Schema 处于加载/错误状态时，顶部显示 Provider Runtime Banner。
- 支持全局快捷键：
  - `Cmd/Ctrl + R`：刷新项目。
  - `Cmd/Ctrl + P`：执行发布。
  - `Cmd/Ctrl + ,`：打开设置。

## 4. Provider Runtime 顶部提示

出现时机：Provider 列表或当前 Provider Schema 正在加载或加载失败。

页面布局：

- 横向横幅位于主工作台顶部，占据固定空间，不遮挡主界面。
- 左侧显示状态图标、标题和说明。
- 右侧显示重试按钮。
- 窄屏下标题说明和按钮可纵向排列。
- 加载态使用旋转图标，错误态使用警告图标。

功能：

- 显示加载中或错误提示。
- 显示具体说明文案。
- 提供重试按钮。
- 加载中时禁用重试按钮。

## 5. 左栏：仓库列表页面

入口：主工作台左侧面板。

页面布局：

- 顶部标题栏左侧显示品牌图标和 One Publish 标识，右侧显示收起按钮。
- 筛选/操作行左侧是“全部 + 数量”，右侧是添加仓库和排序按钮。
- 搜索行使用带搜索图标的输入框，占满面板宽度。
- 列表滚动区按行展示仓库，每行左侧是文件夹图标，中间是名称、路径、分支和 Provider 标签，右侧是更多操作菜单。
- 底部左侧保留设置入口。
- 空态在列表区域居中显示图标、主提示和辅助提示。
- 仓库名是行内第一视觉点，路径和分支使用 muted 色降低权重。

核心功能：

- 展示所有已添加仓库。
- 显示仓库名称、路径、Provider 标签、当前分支。
- 显示分支是否可连接的状态。
- 选择仓库后驱动中栏配置和右侧发布内容。
- 搜索仓库名称或路径。
- 按全部仓库统计数量。
- 空态提示“暂无仓库”，引导添加仓库。
- 支持收起左栏。

仓库操作：

- 添加仓库：
  - 打开目录选择器。
  - 自动检测 Provider。
  - 对需要项目文件绑定的 Provider 扫描项目文件。
  - 扫描 Git 分支。
  - 初始化仓库发布配置。
- 打开目录：调用系统能力打开仓库路径。
- 编辑仓库：打开“编辑项目信息”弹窗。
- 移除仓库：弹出确认框后删除。
- 手动开启排序模式后，可拖拽调整仓库顺序。
- 搜索时禁用拖拽排序，避免筛选列表顺序和全量顺序冲突。

## 6. 编辑项目信息弹窗

入口：仓库行更多操作 -> 编辑仓库。

页面布局：

- 使用 workspace 尺寸弹窗，高度约 82vh。
- Header 显示文件夹图标、标题“编辑项目信息”和说明文字。
- Body 使用两列布局：
  - 左侧摘要栏宽约 240px，展示仓库图标、名称、路径和状态列表。
  - 右侧为可滚动表单区。
- Footer 放取消按钮和保存按钮。
- 左侧作为“当前对象摘要”，右侧作为“编辑区域”。
- 必填校验就地显示在字段下方，保存按钮随扫描、检测、刷新、必填、绑定状态自动禁用。

功能：

- 编辑仓库名称。
- 编辑 Project Root。
- 通过系统目录选择器选择 Project Root。
- 显示当前仓库概要：
  - 名称。
  - 路径。
  - 分支数量。
  - Provider 绑定状态。
  - 当前 Provider。
- 自动扫描项目文件候选。
- 手动刷新项目文件候选。
- 支持 Project File 下拉选择。
- 支持 Project File 手动输入。
- 当 Provider 需要项目绑定且存在多个项目文件时，必须显式选择 Project File。
- 选择或手动清空 Provider。
- 自动检测 Provider。
- 手动重新检测 Provider。
- 展示和选择当前分支。
- 手动刷新分支列表。
- 保存前校验仓库名称和路径不能为空。
- 保存后更新仓库、分支、Provider、项目文件绑定。
- 取消关闭弹窗。

## 7. 中栏：发布配置列表页面

入口：主工作台中间面板。

页面布局：

- 顶部窄标题栏右侧显示收起按钮；左栏收起时额外显示展开仓库按钮。
- 筛选/操作行左侧是配置组筛选，右侧是新建、排序、刷新、配置管理按钮。
- 搜索行使用搜索图标和输入框。
- 列表滚动区按“最近使用 / 项目发布配置 / 自定义配置”分组。
- 分组标题行显示展开箭头、标题、刷新状态和数量。
- 配置行左侧为配置文件或语义图标，中间显示配置名和辅助描述，右侧为更多操作菜单。
- 开启排序模式时，行左侧显示拖拽手柄。
- 配置名称是主视觉点，收藏、复制、查看、编辑、删除收敛进更多菜单。

配置分组：

- 最近使用。
- 项目发布配置（`.pubxml` 等项目内发布配置）。
- 自定义配置（用户保存的配置，按配置组展示）。

核心功能：

- 搜索配置。
- 按配置组筛选。
- 显示当前筛选数量。
- 新建发布配置。
- 刷新配置。
- 打开配置管理。
- 支持收起中栏。
- 左栏收起时支持从中栏展开左栏。
- 手动开启排序模式后支持拖拽排序：
  - 最近使用配置排序。
  - 项目发布配置排序。
  - 自定义配置排序。
- 搜索时禁用拖拽排序。
- 空态显示暂无配置。

最近使用配置功能：

- 点击后恢复对应发布配置。
- 可收藏/取消收藏。
- 可从最近使用列表移除。

项目发布配置功能：

- 点击后选择项目内发布配置。
- 可收藏/取消收藏。
- 可复制为可编辑的自定义配置。
- 可查看完整项目发布配置内容。

自定义配置功能：

- 点击后加载自定义配置。
- 可收藏/取消收藏。
- 可编辑配置。
- 可删除非系统默认配置。
- 系统默认配置不可删除。
- 仅 `.NET` 自定义配置允许直接编辑当前快速配置表单。

## 8. 查看项目发布配置弹窗

入口：中栏项目发布配置更多操作 -> 查看配置。

页面布局：

- 使用 workspace 尺寸弹窗。
- Header 显示查看图标、标题、帮助提示和当前配置名。
- Body 按状态切换：
  - 加载态：居中虚线边框提示。
  - 错误态：红色提示块。
  - 成功态：配置文件路径块、只读发布参数表单、可折叠完整解析参数区。
- Footer 只放关闭按钮。
- 主表单复用创建/编辑配置表单但设为只读，原始 `.pubxml` 细节折叠到补充区。
- 路径和 XML 字段使用等宽字体，方便复制和核查。

功能：

- 加载并解析项目发布配置文件。
- 显示配置文件路径。
- 以只读方式展示可映射到发布表单的参数。
- 展示主表单不能完整表达的 `.pubxml` 补充字段。
- 补充字段默认折叠，包含：
  - XML 分组标签。
  - 节点路径。
  - 节点值。
  - 节点属性。
  - 分组属性。
- 加载失败时显示错误。
- 支持关闭弹窗。

## 9. 创建/编辑发布配置弹窗

入口：

- 中栏“新建配置”按钮。
- 中栏自定义配置更多操作 -> 编辑配置。
- 中栏项目发布配置更多操作 -> 复制为自定义配置后进入保存流程。

页面布局：

- 使用 workspace 尺寸弹窗。
- Header 根据创建/编辑状态切换标题、图标和说明。
- Body 纵向排列多个区块：
  - 快速模板卡片。
  - 基础信息区。
  - 发布参数区。
  - 输出与部署区。
  - 高级参数区。
- Footer 左侧提示保存后行为，右侧放取消和保存按钮。
- 宽屏下配置名称/配置组、配置类型/运行时、输出目录/自包含部署等表单项两列排列；窄屏退化为单列。
- 高级参数默认降低存在感，常用字段直接展示，其余字段折叠。
- 属性表使用“属性名 / 属性值 / 操作”三列。

功能：

- 创建新配置或编辑已有配置。
- 选择快速模板。
- 展示模板说明。
- 输入配置名称。
- 选择发布配置组。
- 选择已有分组。
- 输入自定义分组。
- 保存后立即写入并应用到当前仓库。

.NET 基础发布参数：

- 配置类型：`Release` / `Debug`。
- 运行时：
  - 框架依赖。
  - Windows x64。
  - macOS ARM64。
  - macOS x64。
  - Linux x64。
- 输出目录。
- 输出目标类型提示：
  - 本地路径。
  - UNC 路径。
  - 挂载路径。
  - 远程路径后缀提示。
- 自包含部署开关。
- 未指定运行时时禁用自包含部署。

.NET 高级参数：

- 目标框架（支持从当前项目目标框架中建议，也支持手动输入）。
- 跳过构建（`--no-build`）。
- 跳过还原（`--no-restore`）。
- 日志详细级别（`--verbosity`）。
- 隐藏 .NET 标识（`--no-logo`）。
- 发布前清空目标目录。
- 单文件发布（`PublishSingleFile`）。
- 其余 MSBuild 属性表：
  - 添加属性。
  - 编辑属性名。
  - 编辑属性值。
  - 删除属性。
- 常用高级字段直接展示，其余字段可折叠查看。

## 10. 配置管理弹窗

入口：中栏“配置管理”按钮。

页面布局：

- 使用 workspace 尺寸弹窗。
- Header 显示标题“配置管理”和说明“管理、导入、导出发布配置文件”。
- Body 分为配置文件操作区、保存当前配置区、已保存配置列表区，并可打开导入确认子弹窗。
- Footer 左侧显示说明，右侧放关闭按钮。
- 配置文件操作区在宽屏下用两列按钮放导出和导入。
- 保存当前配置区由名称输入框、保存按钮和辅助说明组成。
- 已保存配置以卡片行展示，左侧是名称、默认标签、Provider、日期，右侧是加载和删除按钮。
- 导入确认子弹窗使用 compact 尺寸，列表展示配置名和 Provider。

功能：

- 刷新当前仓库配置列表。
- 导出配置到 JSON。
- 从 JSON 导入配置。
- 导入前预览待导入配置列表。
- 确认导入后刷新配置列表。
- 保存当前参数快照为配置。
- 输入新配置名称。
- 展示已保存配置列表。
- 显示配置 Provider 和创建日期。
- 加载配置并关闭弹窗。
- 删除非系统默认配置。
- 系统默认配置显示“默认”标签，不允许删除。
- 关闭弹窗。

## 11. 右侧主页：发布执行页面

入口：右侧顶部“主页”按钮。

显示条件：

- 有发布动作、执行日志、发布结果，或当前正在刷新发布卡片。

页面布局：

- 右侧内容滚动区内使用居中最大宽度容器。
- 命令导入映射结果卡片显示在发布卡片上方。
- 发布执行卡片占据主要高度，内部从上到下依次是标题区、命令预览、动作按钮行、发布状态摘要、输出目录/失败原因/警告摘要、终端日志。
- 动作区按状态变化：
  - 未运行时主按钮为“执行发布”。
  - 发布中主按钮禁用并显示运行状态，旁边显示取消发布。
  - 成功后主按钮变为打开输出目录，次按钮为重新发布。
- 状态摘要左侧是状态图标块，右侧是状态标题、徽标、文件数量和说明。
- 终端区域使用深色背景和等宽字体，长命令和路径自动换行。
- 发布状态比日志更优先，失败时失败原因和日志保留在同一视野中。

功能：

- 显示将执行的命令预览。
- 执行发布。
- 发布中显示运行状态。
- 发布中支持取消发布。
- 取消中显示取消状态。
- 发布成功后：
  - 显示成功状态。
  - 显示文件数量。
  - 显示输出目录。
  - 支持打开输出目录。
  - 支持重新发布。
- 发布失败后：
  - 显示失败状态。
  - 显示失败原因。
  - 保留终端日志用于排查。
- 发布取消后：
  - 显示已取消状态。
  - 支持调整参数后重新发布。
- 成功但有警告时：
  - 显示警告数量。
  - 可展开查看警告列表。
- 终端日志：
  - 无结果或执行中默认展开。
  - 有执行结果后默认收起。
  - 显示日志行数。
  - 支持展开/收起。
- 刷新项目或解析项目配置时，发布卡片会冻结旧内容并显示刷新遮罩，避免界面跳动。

发布前校验/预检能力：

- 未选择仓库时阻止执行。
- 需要 Project File 但未解析出项目时阻止执行。
- 根据当前选择构建 ProviderPublishSpec。
- 渲染命令预览。
- 执行发布预检。
- 预检失败时可打开环境检查。
- 受保护输出路径失败时有恢复流程。
- 记录最近使用配置。
- 发布完成后生成执行记录。
- 发布完成/失败/取消时发送应用事件和通知。

## 12. 命令导入映射结果卡片

入口：命令导入成功后在右侧内容区显示。

页面布局：

- 标准卡片容器，最大宽度与发布内容一致。
- Header 显示导入图标、标题“命令导入映射结果”和 Provider 描述。
- Body 分为成功映射字段块和未映射字段块。
- 成功映射使用绿色提示块，未映射使用警告色提示块。
- 两块都显示数量和字段列表，方便快速判断导入质量。

功能：

- 显示当前 Provider。
- 显示已映射字段数量和字段名。
- 显示未映射字段数量和字段名。
- 用于确认 CLI 命令解析到结构化参数的结果。

## 13. 右侧历史记录页面

入口：右侧顶部“历史记录”按钮。

显示条件：

- 当前已选择仓库。
- 当前仓库存在执行历史。

## 24. 整体设计风格

OnePublish 当前界面更接近“密集工程工作台”，不是营销型页面，也不是大面积装饰型仪表盘。视觉重点是快速扫描、稳定布局、明确状态和低干扰操作。

### 24.1 视觉语言

整体风格：

- Geist 风格为主：克制、清晰、工程工具感强。
- 低圆角：常见容器使用 `rounded-sm` / `rounded-md`，避免过度圆润。
- 细边框分层：通过 `border-border`、浅色背景和轻微阴影表达层级。
- 中性色为底：大面积使用背景色、卡片色、muted 色；只在状态和主操作上使用强调色。
- 密集信息排布：列表行、筛选控件、操作按钮都偏紧凑，适合重复操作。
- 状态色明确：
  - 成功：绿色。
  - 失败：红色。
  - 警告/取消：琥珀色。
  - 信息/主交互：蓝色。
- 图标体系统一使用 Lucide，按钮优先用图标表达动作。
- 滚动条默认弱化，仅在滚动区域 hover 时显现。

### 24.2 色彩与表面

主要表面类型：

- `bg-background`：应用底色。
- `bg-card`：主要内容和列表滚动区底色。
- `surface-raised`：主面板、右侧内容外壳、侧栏外壳。
- `surface-modal`：弹窗主体。
- `surface-input` / `search-input-shell`：输入框、搜索框、设置项中的可输入区域。
- `bg-muted`：代码块、提示块、只读信息块、次级内容块。

颜色使用原则：

- 主体页面不使用大面积强色块。
- 蓝色只强调主操作、选中状态、当前步骤、可执行提示。
- 绿色、红色、琥珀色只用于结果状态，不参与常规装饰。
- 代码、路径、命令使用等宽字体和 muted 背景，降低视觉重量但保证可读。

### 24.3 字体与信息层级

字体风格：

- 使用 Geist 字体体系。
- 大标题很少出现，主界面主要使用 `text-heading-20`、`text-heading-16`、`text-heading-14`。
- 列表项以 `text-label-13` / `text-label-14` 为主，强调可扫描性。
- 路径、命令、sha256、执行结果使用 `font-mono`。
- 分组标题多使用小字号、半粗体、uppercase、较大字距，形成工具面板感。

信息层级：

- 一级：当前工作对象和执行状态。
- 二级：仓库、配置、历史记录列表。
- 三级：路径、说明、时间、辅助提示。
- 状态徽标放在内容旁边，不单独占据大面积空间。

### 24.4 交互与动效

交互风格：

- hover 主要改变背景色和图标色，不做夸张位移。
- selected 状态使用浅色背景和强调色图标。
- loading 使用 `Loader2` 旋转图标。
- 拖拽排序只在显式开启排序模式后出现拖拽手柄。
- 搜索时禁用排序，避免用户误以为筛选列表顺序就是全量顺序。
- 设置、列表、弹窗都保留键盘可访问焦点态。
- 遵守系统 reduced motion 设置，减少动画时长。

### 24.5 布局原则

布局基调：

- 先展示真实工作区，不做首页宣传页。
- 主界面固定为三栏工作台，用户大部分时间不离开这个结构。
- 侧栏负责选择上下文，右栏负责执行和回顾。
- 面板可收起，避免在小窗口里占用关键空间。
- 弹窗用于临时任务：编辑、设置、检查、导入、确认。
- 长内容必须进入内部滚动区，外层窗口不被撑破。
- 弹窗统一有 Header、Body、Footer，操作按钮放底部。

### 24.6 响应式与窗口约束

响应式策略：

- 主窗口以桌面端为主，使用 `h-screen` 固定视口高度。
- 三栏使用固定宽度 + flex 自适应：左右栏稳定，右侧内容吃掉剩余空间。
- 列表和主内容都使用 `min-w-0`、`overflow-auto`，防止长路径和命令撑破布局。
- 弹窗尺寸分为 `compact`、`default`、`wide`、`workspace`、`responsive`。
- 工作区型弹窗使用 `h-[82vh]`，内部再分栏和滚动。
- 表单在宽屏下多列排列，在窄屏下退化为单列。
